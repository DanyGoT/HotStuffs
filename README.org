#+title: HotStuff

DiemBFT v4 in Go, over Gorums. DiemBFT is a variant of HotStuff that commits
on two consecutive rounds instead of three. The code follows the pseudocode in
section 3 of the paper.

* Running

#+begin_src sh
go run ./cmd/diem -local 4 -time 10s
#+end_src

This runs four replicas in one process for ten seconds and prints how many
blocks each one committed. =-h= lists the other flags, including the ones for
running one replica per process.

=make test= runs the tests. =make proto= regenerates the protobuf code and
needs =nix develop=.

[[./doc/experiments/README.org][doc/experiments]] covers running on the UiS VMs, and the results.

* Layout

- =diem/= is the protocol. It has no networking and runs on one goroutine.
- =diemnet/= sends and receives its messages over Gorums.
- =proto/diempb/= defines the messages.
- =crypto/= signs and verifies them.
- =replica/= puts the pieces together into a running replica.
- =cmd/diem/= is the program.
- =scripts/= runs benchmarks on the UiS machines.
- =doc/= holds the project brief, meeting notes, experiments, known limits and
  papers.

=diem/README.org= explains the protocol code in more detail.
